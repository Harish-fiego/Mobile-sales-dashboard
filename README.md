# 📱 Mobile Sales Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Mobile Sales Dashboard** built using **Microsoft Power BI**. The dashboard provides a comprehensive analysis of mobile phone sales performance across different brands, cities, payment methods, and mobile models.

The objective of this project is to transform raw sales data into meaningful business insights through interactive visualizations, KPIs, filters, and data analysis.

## 📈 Dashboard Features

### 📅 Orders Trend by Month

The dashboard provides a monthly analysis of order trends, helping identify changes in sales activity throughout the year.

### 🏷️ Top Brands

The Top Brands visualization compares the number of orders across different mobile brands.

* Motorola recorded approximately **1.648K orders**.
* Nothing recorded approximately **1.647K orders**.
* Apple recorded approximately **1.572K orders**.
* Google recorded approximately **1.567K orders**.
* OnePlus recorded approximately **1.556K orders**.

### 💰 Revenue by Brand

The dashboard compares revenue generated by different mobile brands.

* Motorola generated approximately **36M** in revenue.
* Nothing generated approximately **36M**.
* OnePlus and Google generated approximately **34M** each.
* Apple generated approximately **33M**.

### 💳 Payment Method Analysis

The payment method visualization shows how customers use different payment options for their purchases.

The dashboard includes payment methods such as:

* UPI
* Cash
* Credit Card
* Debit Card
* Wallet
* Net Banking

### 📱 Top Selling Mobile Models

The treemap visualization identifies the top-selling mobile models based on quantity sold, allowing easy comparison between individual products.

### 🌍 Brand & City Analysis

Interactive filters allow users to analyze sales data based on **Brand** and **City**, making it easier to explore specific segments of the dataset.

## 🎯 Project Objective

The main objective of this project is to analyze mobile sales data and create an interactive business intelligence dashboard that helps users:

* Monitor monthly order trends
* Compare brand performance
* Analyze revenue by brand
* Understand customer payment preferences
* Identify top-selling mobile models
* Explore sales performance across different cities
